# CodexAgentPlayground
Playground for CodexAgent project

## Приложение на C++

Сборка (требуются GNU Make и компилятор C++17):

```sh
make
./greeting
```

Введите имя пользователя и нажмите Enter. Для имени `root` программа выводит
`Здравствуйте, root!`, для любого другого имени — `пользователь не найден`.
Имя сравнивается целиком, с учётом регистра и пробелов.
После приветствия `root` выводится текущее местное время в формате
`Текущее время: ГГГГ-ММ-ДД ЧЧ:ММ:СС`.

Для запуска тестов выполните `make test` (требуется Python 3).

Для удаления собранной программы выполните `make clean`.
