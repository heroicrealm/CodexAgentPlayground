# CodexAgentPlayground
Playground for CodexAgent project

Build and run the C hello world program:

```sh
cc -std=c11 -Wall -Wextra -Werror hello.c -o hello
./hello
```

Expected output (10 lines):

```text
hello world
hello world
hello world
hello world
hello world
hello world
hello world
hello world
hello world
hello world
```
